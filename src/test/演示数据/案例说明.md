## 两种体验方式

- **直接看案例**：首页点击「看案例」，或选择三类场景。网站使用自带的 Alex Tan 合成画像，不会自动导入本文件夹的 JSON。
- **验证完整项目和记录**：通过顶部「记录管理 → 导入记录」，选择上述任一 JSON 并确认；随后查看「我的优势 → 职业方向 → 行动计划」。文件包含项目内容、交付物、就业状态、转型原因、当前优先事项、未来目标和分类 AI 使用情况。

虚构记录中保存的每周时间为初始建议，尚未确认；请在选定职业方向后自行确认。确认时间或主动自评能力后，分数可能变化。

案例 01 优先恢复收入，投递与补缺同时进行；案例 02 保留工作并行准备；案例 03 先安排学习和项目练习。处境影响行动策略，不把家庭责任或离职本身等同为能力差异。

## 记录测试

1. 导入任一虚构记录，查看项目与处境。
2. 收藏方向、生成计划、免费体验 Pro，并勾选一项周任务。
3. 「记录管理 → 导出记录」，保存下载的 JSON。
4. 在准备好的测试浏览器中删除记录并确认，再导入刚导出的 JSON，检查项目、收藏和任务进度恢复。不要删除未备份的真实记录。
