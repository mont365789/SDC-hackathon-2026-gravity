# RePath AI｜评委体验说明

Demo 地址：https://repath-ai-0-2.lianghuihu.chatgpt.site

## 约 3 分钟体验

1. **打开链接 → 选择演示案例**：首页点击「看案例」，或选择「转型求职 / 在职进阶 / 重返职场」。无需从零填写资料，产品内无需注册。
2. **查看结果**：在「转型案例」查看已有能力、推荐职业方向和待补能力；点击「查看更多方向」比较 8 个方向。
3. **查看行动方案**：选择一个方向 →「查看准备方案」→ 选择每周时间 →「生成我的行动计划」。Free 可看起步任务和第 1 周预览。
4. **体验 Pro**：点击「体验我的完整周计划」，免费查看完整周任务、进度、技能复盘、方向对比和计划下载，无需付款。

## 可以验证的功能

| 功能 | 预期表现 |
|---|---|
| 三类虚构案例 | 切换背景后，推荐方向与能力差距随之变化 |
| 职业方向 | 8 个方向，可分类、翻页、查看岗位任务与来源依据；匹配分数不代表录用概率 |
| 行动计划 | 先选方向，再确认每周时间；可调整时间并重新生成 |
| Free / Pro | Free 提供探索和首周预览；Pro 演示完整计划、任务勾选、主动自评、对比和 TXT 下载 |
| 语言与主题 | 中文 / English / Melayu，深色 / 浅色切换 |
| 收藏与记录 | 收藏方向；通过「记录管理」导出、导入和确认删除个人记录 |

## 完整虚构记录（可选）

要验证「我的优势」、当前处境和记录备份，可在「记录管理 → 导入记录」选择本文件夹「演示数据」中的任一 JSON，查看摘要后确认。文件已包含项目经历与处境，无需输入个人资料。

导入会替换当前浏览器的个人记录，请先导出已有记录。三个文件均为虚构，初始为 Free；选择方向和准备时间后可免费体验 Pro。内置「看案例」的练习进度属于示例体验，不会进入个人记录备份；请用导入的虚构记录验证导出、恢复与刷新保留。

## 打开方式与范围

- 在线站点当前仍限制为项目所有者访问，评委需先获得托管访问权限；产品内「无需注册」不等于网站托管公开。
- 若尚未开通在线访问，**直接双击「本地演示.html」**即可体验同一最终版。已内置资料快照，外部链接和在线刷新需要网络。
- 本项目为比赛前端 Demo：账户和订阅为演示，RM 19/月为概念定价；职业匹配在浏览器运行，未接入运行时大模型服务或真实招聘投递。
