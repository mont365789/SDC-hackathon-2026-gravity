# RePath

当前页面为 RePath 主版本，不显示版本编号。源码目录沿用 0.2 名称以保留版本历史；0.1 原站、快照与预填演示保持冻结。

- 在线版：https://repath-ai-0-2.lianghuihu.chatgpt.site
- 本地运行：`node server.mjs`，打开打印的 localhost 地址。
- 单文件版：`node scripts/package-demo.mjs`，生成上级目录 `RePath-0.2.html`。
- 验证：`node --test tests/*.test.mjs`。

## 本次更新

- 顶栏新增“记录管理”：导出 JSON 备份、预览后确认导入，以及确认后删除当前浏览器的个人记录；包含项目经历、当前情况、收藏、行动计划、周进度和自评。保留语言与主题设置，演示案例不混入备份。
- 顶栏、页脚与浏览器图标改用用户选定的平面蓝色 R / RePath 标志；两种主题保持图形原色，分别使用深蓝和浅色字标。

- 冷白、青蓝到蓝紫渐变标题，分层卡片、悬停反馈与入场动效；尊重减少动态效果设置。
- 顶栏深色 / 浅色切换，记住选择；切换主题不会重建表单或清空正在填写的内容。
- 中文、English、Bahasa Melayu。首页维持一屏布局；方向页采用分类、分页与同屏详情。
- 8 个职业方向：项目管理、管理分析、市场研究、商业智能、软件开发、培训发展、物流、采购。
- 新增 SQL、开发维护、测试排查、培训带教、采购评估等具体能力。AI 使用仍为单独的可选记录，不成为雷达维度或通用加分项。
- 方向页显示已有能力、待补能力、独立的本地需求观察和岗位证据。按经验匹配或相关职业类别趋势排序。
- 保留项目经历 → 当前处境 → 方向 → 准备方案，以及 Free / Pro、收藏、周进度、自评与导出。

## 匹配与排序

个人适配分数保持独立：未确认学习时间时，技能覆盖与经验迁移按 35:25 归一化；确认时间后按 35:25:15 加入学习可行性。学习时长与经验年限系数为演示规则，不代表完整转岗资格或录用概率。

市场趋势是单独可选的列表顺序：只用可对应的相关职业类别（市场、软件）的 Q1/Q2 环比排序；大类与未知数据放后面。改变来源快照会重新计算类别差值与趋势顺序，个人适配分数不变。其余未经过验证的权重不进入市场分数。人工映射见 `dist/market-evidence.mjs`。

当前处境决定先求职还是先学习；裁员本身不会自动推断收入压力。年龄、性别不用于匹配。能力由用户确认，勾选周任务不自动增加能力。

## 验证与交付边界

29 项测试覆盖匹配、计划、场景、AI 独立记录、来源变化重排、类别缺失、RSS 空结果、网络失败、记录备份往返、无效文件拒绝与导入字段校验。浏览器验证了深浅主题、表单保留、方向分类与详情、来源弹窗、语言和一屏首页；使用模拟数据验证导出、删除取消/确认、重新导入与刷新后保留，检查 320px、390px 和桌面记录管理布局。单文件包检查内联 JavaScript 语法。

这是前端比赛 Demo：无模型 API、真实招聘抓取、生产账户、付款或就业效果验证。Pro 可免费体验，RM 19/月为概念定价。用户数据只在当前浏览器，无跨设备同步。Sites 保持已有的私有访问范围；产品内演示身份与托管平台登录相互独立。
